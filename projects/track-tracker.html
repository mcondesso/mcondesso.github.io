The problem

Getting a playlist onto a USB stick for a DJ set is death by a thousand steps: find each track somewhere, download it, check the audio actually plays on the gear, fix the tags, convert formats. Track Tracker turns that into a single run. Give it an Exportify CSV, or log into Spotify or Tidal and pick a playlist directly, or paste a YouTube playlist URL — matching, downloading and conversion run one after another with a progress bar and log for every stage.

What it does

Many sources

Spotify and Tidal login, public/unlisted YouTube playlist URLs, Exportify CSVs, individual SoundCloud track URLs, or a folder of files you already have.

Smart matching

Finds the right YouTube video per track and guards against classic false positives — multi-artist collabs, "Original Mix" tails that wreck search ranking.

Clean downloads

Audio-only streams losslessly remuxed out of YouTube's fragmented DASH MP4 into a standard container, so hardware players accept them. Title and artist written to tags.

Hardware-compat check

Scans files against Pioneer / AlphaTheta CDJ & XDJ profiles and reports a fix for each issue — HE-AAC / Opus / ALAC codecs, odd sample rates, WAV header traps.

Browser UI or CLI

streamlit run app.py for progress bars and playlist pickers, or ./run.sh playlist.csv to script the whole pipeline headless.

Resumable

Recovers tracks stranded in transient states after an interrupted run and skips anything already downloaded, so re-running is cheap.

How it works

Match

For each track it builds a query from name, artists and duration, searches YouTube, and picks the best candidate — falling back to a stripped query when decorated titles break ranking. YouTube-sourced playlists arrive pre-matched and skip this stage.

Download

Pulls the audio-only stream, losslessly remuxes it into a standard container, and writes Title and Contributing Artists into the file's metadata.

Convert & verify

Transcodes everything to MP3 (preserving tags), then runs the hardware-compatibility checker so you know each file will load on the deck before you copy it to a USB stick.

Built with

Python 3.10+, streamlit for the UI, spotipy and tidalapi for playlist access, pytubefix + ytmusicapi for YouTube, mutagen for tagging, ffmpeg / moviepy for conversion, and librosa for audio analysis. Packaged with Poetry.
