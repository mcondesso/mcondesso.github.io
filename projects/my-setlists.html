The problem

Setlists live in scattered notes apps, DMs, and memory. My Setlists gives them a proper home: register, build a setlist, search Discogs for each track instead of typing metadata by hand, drag tracks into the order they'll actually play, and mark the setlist public so anyone can browse it — or keep it private, just for yourself.

What it does

Accounts

Register and log in with a JWT-backed session; passwords hashed with Argon2 via pwdlib, auth endpoints rate-limited against brute force.

Public or private setlists

Every setlist is public or private, owned by the account that created it. "My setlists" and "Public setlists" are listed separately, paginated with "Load more".

Discogs search

Add a song by searching Discogs and picking the right release — no manual typing of title, artist or duration. Repeat picks reuse and backfill the same song record.

Drag to reorder

A setlist's owner can drag songs into a new running order — the order everyone else sees when they open it.

Count & total duration

Each song's duration is tracked and rolled up into a song count and total playback time shown on the setlist page.

Song detail page

Every song has its own page with links out to Discogs and YouTube, plus a picker for adding it to any of your setlists.

How it works

Create

Register, log in, and start a setlist as public or private. The JWT session refreshes quietly in the background so an open tab stays logged in.

Build

Search Discogs for each track, add the right result, and drag songs into the order the setlist should play in.

Share

Public setlists show up for anyone to browse and open; private ones stay visible only to their owner.

Built with

Backend: FastAPI + SQLModel over PostgreSQL, Alembic migrations, JWT auth via PyJWT, pwdlib (Argon2) for password hashing, and slowapi for rate limiting — tested with pytest. Frontend: a Vite + Svelte 5 SPA in TypeScript, no routing or state library — a small hash router and Svelte 5 runes cover it — tested with Vitest, @testing-library/svelte and end-to-end with Playwright.
